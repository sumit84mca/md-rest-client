# Security Policy

## Supported Versions

Only latest `main` branch and latest Marketplace release are supported for security fixes.

## Reporting a Vulnerability

Please do not open a public issue for vulnerabilities.

Report privately with:

1. Affected version or commit
2. Reproduction steps
3. Impact assessment
4. Suggested fix (if available)

Use GitHub Security Advisories ("Report a vulnerability") for this repository when possible.

If advisory flow is unavailable, open a private contact request via repository owner profile and include "md-rest-client security report" in subject.

## Response Targets

1. Initial acknowledgement: within 3 business days
2. Triage decision: within 7 business days
3. Fix timeline: based on severity and exploitability
